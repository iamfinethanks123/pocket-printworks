적용 범위

이 정책은 Pocket Printworks iOS 앱에 적용됩니다. 싱글 플레이는 오프라인으로 즐길 수 있으며, 개발자 자체 계정, 광고, 앱 간 추적은 없습니다. Game Center가 온라인 대전과 순위표를 제공하고, 구매는 Apple이 처리합니다. iCloud 진행 상황 동기화와 기기 내 플레이테스트 연구 기록은 모두 기본적으로 꺼져 있으며 직접 켜야 합니다.

기기에 저장되는 데이터

진행 상황, 작업 라인 초안, 별, 완료 시간, 인쇄 방법 메모, 직접 만든 퍼즐, 언어와 기타 설정은 이 기기에 저장돼요. iOS 시스템 백업에 앱 데이터가 포함되는지는 기기와 백업 설정에 따라 달라요.

완전판 구매

처음 여섯 장의 본편 의뢰 150개, 입문, 기초 연습, 친구 대전은 무료입니다. 완전판은 Apple이 검증하고 결제하는 일회성 비소모성 구매입니다. 개발자는 결제 카드 정보를 받지 않습니다. 기기를 바꾸거나 다시 설치한 뒤 같은 Apple 계정으로 구매를 복원할 수 있습니다. 체력 티켓을 판매하거나 사용하지 않으며 iCloud 티켓 지갑도 사용하지 않습니다.

친구 대전 및 순위표

친구 방을 만들거나 참가할 때에만 앱이 Game Center를 통해 플레이어 이름, 방 정보, 퍼즐, 작업 라인, 라운드 상태, 이벤트 사이의 시간 간격을 교환합니다. 초대 링크에는 6자리 방 코드만 포함되며 정답은 포함되지 않습니다. 링크를 연 뒤 직접 참가를 확인합니다. 순위표는 로그인하고 공유를 켠 경우에만 조건을 충족하는 장의 첫 완료 총시간을 전송합니다. 앱은 이 데이터를 개발자 서버에 자동으로 전송하지 않습니다.

iCloud 진행 상황 동기화

켜면 완료한 의뢰, 작품, 저장한 인쇄 방법, 직접 만든 퍼즐, 별 개수가 비공개 iCloud Drive의 앱 컨테이너에 저장되며, 저장과 동기화는 Apple이 처리합니다. 같은 iCloud 계정을 사용하는 기기는 유효한 진행 상황을 병합하지만, 기기 내 미완성 작업 라인, 기기 설정, 구매 권한, 연구 기록은 덮어쓰지 않습니다. iCloud 계정을 바꾸면 동기화가 중지되며, 다시 켤지 직접 선택해야 합니다. 앱은 저장 데이터나 iCloud 로그인 정보를 개발자에게 자동으로 전송하지 않습니다. 직접 내보내 공유하는 경우에는 아래 설명에 따라 처리됩니다.

Game Center 최초 완료 기록 동기화

Game Center에 로그인한 경우 같은 플레이어의 앱 내 최초 완료 기록도 iCloud로 병합합니다. 다른 플레이어의 기록이나 미등록 기록은 이전하지 않으며, 다른 기기에서 순위표 공유 동의를 자동으로 켜지 않습니다.

선택적 플레이테스트 연구 기록

기본적으로 꺼져 있습니다. 켜면 앱이 플레이 이벤트, 시간, 퍼즐 또는 장 번호, 완료까지 걸린 시간, 힌트, 구매 및 복원 결과를 기록합니다. 이름, 이메일 주소, Game Center 또는 iCloud 식별자, 거래 번호, 결제 정보는 포함되지 않습니다. 기록은 기기에만 보관되며 최대 1,000개입니다. 앱을 열 때 30일이 지난 기록을 정리합니다. 자동으로 업로드하거나 iCloud에 동기화하지 않으며, 게임 백업에도 포함하지 않습니다. 기록을 끄거나 지우거나 수동으로 내보낼 수 있습니다. 별도로 공유하기를 선택한 경우에만 받는 사람이 파일을 받게 됩니다.

파일 가져오기 및 공유

가져오기를 선택한 경우에만 지정한 파일을 읽어요. 백업이나 작품을 내보내면 선택한 저장 위치, 수신자와 서비스가 해당 파일을 받게 돼요. 전체 백업에는 직접 만든 퍼즐 이름, 게임 기록과 설정이 포함될 수 있어요.

지원 이메일

직접 지원 이메일을 보낸 경우에만 개발자가 이메일 주소, 메시지와 선택한 첨부 파일을 받아요. 이메일은 사용 중인 이메일 서비스를 통해 처리되며 답변과 문제 해결에 사용돼요. 필요한 정보만 보내 주세요. 앱은 이메일을 자동으로 보내거나 저장 데이터를 첨부하지 않아요.

권한 및 시간 측정

혼자 플레이할 때는 연결 권한이 필요 없으며 온라인 대전은 Game Center를 사용합니다. 기기 타이머는 플레이와 대전 이벤트의 간격을 측정합니다. 기기의 원시 가동 시간은 전송하거나 기기 식별 및 추적에 사용하지 않습니다.

데이터 보관 및 삭제

설정에서 기기 내 진행 상황을 초기화할 수 있습니다. 앱은 복원 가능한 사본을 보관하고 진행 상황 동기화를 끄지만, Apple 구매 항목은 취소하지 않습니다. 동기화를 끄거나 앱을 삭제해도 iCloud의 이전 저장 데이터는 삭제되지 않으며, 시스템의 iCloud 저장 공간 설정에서 관리할 수 있습니다. 연구 기록은 앱 설정에서 지울 수 있습니다. 내보낸 파일, 시스템 백업, 친구가 받은 콘텐츠는 별도로 처리해야 합니다. 지원 이메일은 문제 해결에 필요한 기간에만 보관합니다. 문의하거나 삭제를 요청하려면 아래 이메일 주소로 연락해 주세요.
